# Rock Paper Scissors

Hey everyone! My Project is Rock Paper Scissors Game in C. I made this project in order to practice C and implement what I have learnt so far.

## How to use ?

I would say , the simplicity is the most highlighting part of this project . You navigate using only the Arrow Keys, Enter key and pressing X (to exit or go back).
Just open the Game.exe file and play

If you want to open via terminal

- **Compile it**

  ```bash
  gcc Game.c -o Game.exe
  ```

  (make sure you have gcc compiler installed in your computer)

- **Run it**

  ```bash
  ./Game.exe
  ```

## Features

- Playing Rock Paper Scissor with bot
- Looking at the reports
- Navigate using arrow keys
- Saving Reports in another text file to not lose score after closing the game


## What I learnt

By making this project , I was able to practice and implement concepts like Pointers , Function , FILE and some confusing nested loops and breaking the loops using break.

Also most new thing is learning how to make navigation menu .
